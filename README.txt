The JJ's Wedding Invitation Website
===================================
Files included:
- index.html  (Semantic HTML structure)
- styles.css  (Responsive layout, typography, glassmorphism, and card design)
- script.js   (Live countdown timer, ?guest= personalization, WhatsApp RSVP links, .ics calendar download)

How to use:
1. Extract all files into the same folder.
2. Save your couple background photo in that same folder as `couple.jpg` (or update the `url("couple.jpg")` path in `styles.css`).
3. Open `index.html` in any web browser, or upload the folder to GitHub Pages, Netlify, or Vercel.
